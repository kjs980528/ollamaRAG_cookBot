# 🍳 쿡봇(CookBot) - PDF 기반 멀티모달 요리 레시피 챗봇 에이전트

`cook_pdf` 디렉터리에 있는 전문 요리책 PDF를 분석하여, 사용자의 요리 질문에 맞춰 **상세 레시피(재료, 조리 단계, 셰프 팁)**와 **실제 요리/조리 사진**을 함께 제공하는 Flask 기반 RAG(Retrieval-Augmented Generation) 챗봇 웹 애플리케이션입니다.

---

## 🌟 주요 기능 및 특징

1. **Ollama `qwen3:8b` 기반 요리사 에이전트**
   - 친절하고 전문적인 셰프 페르소나 탑재
   - 재료 준비, 조리 단계(1, 2, 3...), 팁, 출처 페이지까지 체계적 안내

2. **멀티모달 이미지 연동 (요리 사진 제공)**
   - PDF 내부에서 추출된 **830여 개의 고해상도 요리 및 조리 과정 사진** 매핑
   - 답변 마크다운 본문에 요리 사진 자동 삽입
   - 답변 하단에 **"요리책 속 조리 & 완성 사진" 카드 갤러리** 자동 표시
   - 이미지 클릭 시 고화질 **라이트박스(Lightbox) 모달**로 확대 보기 지원

3. **PDF 원본 페이지 뷰어 지원**
   - 참고 출처 배지 클릭 시 해당 PDF 페이지를 온디맨드로 고화질 렌더링하여 모달로 즉시 열람 가능

4. **원클릭 [요리책 동기화] 기능 탑재**
   - `cook_pdf` 폴더에 새로운 PDF를 넣은 뒤, 웹 화면 사이드바의 **[동기화]** 버튼 클릭 한 번으로 새 요리책의 이미지 추출 + 벡터 DB 재구축이 백그라운드에서 자동 진행됩니다.

5. **모던 반응형 웹 UI (Flask + Tailwind CSS)**
   - 깔끔하고 따뜻한 오렌지/앰버 셰프 테마
   - 원클릭 추천 질문 칩 (김 주먹밥, 김치찌개, 연두부 샐러드, 참치마요 덮밥 등)
   - 모바일 및 데스크톱 완벽 대응 반응형 사이드바

## 🚀 실행 방법

### 1. 가상환경 활성화 및 패키지 확인
```bash
.\venv\Scripts\activate
```

### 2. Ollama 실행 및 모델 준비
```bash
ollama run qwen3:8b
ollama pull bge-m3
```

### 3. 웹 서버 실행
```bash
python run_app.py
```
실행 후 웹 브라우저에서 **http://localhost:5000** 에 접속하세요!
